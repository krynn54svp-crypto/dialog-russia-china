# Диалог Россия — Китай

Русскоязычный учебный практикум по межкультурной деловой коммуникации для студентов и начинающих специалистов.

## Содержание

- Теоретические основы и культурный контекст.
- Четыре этапа переговоров и шесть учебных ситуаций с разбором.
- Двенадцать формулировок, восемь терминов и структура резюме встречи.
- План подготовки с сохранением, скачиванием и печатью.
- Заметки для рефлексии и рекомендации для преподавателя.

## Публикация в GitHub Pages

Сайт готов к публикации без сборки и дополнительных зависимостей. В настройках репозитория откройте **Pages**, выберите **Deploy from a branch**, ветку **main** и папку **/(root)**. Файл `.nojekyll` отключает обработку Jekyll.

Пользовательские записи сохраняются только в браузере. После перехода с другого домена прежние локальные заметки автоматически не переносятся. Функции сайта не требуют входа в GitHub.

Учебные сценарии являются моделируемыми примерами, а не эмпирическими результатами исследования.
